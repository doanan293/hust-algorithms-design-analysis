\section*{Data and Code Availability}
\addcontentsline{toc}{section}{Data and Code Availability}

The source code, scenario manifests, experiment configurations, and raw results are available in the project repository, together with a script that regenerates every table and figure of this paper from the stored results and checks them against the committed versions. Topology Zoo, SNDlib, and RescueNet are publicly available from their original sources; the RescueNet images and masks are not redistributed, and only the extracted target manifest is provided.
